## 1. NexusRAG 品牌 README 与双重许可

### 背景与目标

产品定名 **NexusRAG**，需在 GitHub/Gitee 展示完整项目说明（徽章、产品亮点、能力快照），并明确 **商业用途须单独书面授权**，同时保留 RAGFlow 上游 Apache-2.0 合规说明。

**用户可见变化**：根 README 居中品牌区 + Gitee/GitHub 徽章 + 产品概览图；License 章节改为双重许可表格；新增商业授权申请文档。

### 改动摘要

- 根 `README.md`：NexusRAG 品牌头、技术栈/Star 徽章、四象限产品亮点、v1 能力快照、概览图 `docs/assets/nexusrag-overview.png`。
- 新增 `LICENSE`（NexusRAG Source Available v1.0）：非商业免费，Commercial Use 须 Commercial License。
- 新增 `LICENSE.zh-CN.md`、`COMMERCIAL-LICENSE.md`、`THIRD-PARTY-NOTICES.md`、`licenses/Apache-2.0.txt`。
- `frontend/rag3-web/README.md` 标题同步 NexusRAG。

### 验证与风险

- 验证：Markdown 链接与徽章 URL 可点击；License 文件存在于仓库根目录供 GitHub 识别。
- 风险：Monorepo 含 RAGFlow Apache-2.0 衍生代码，**不能**对全仓单一闭源；商业条款仅覆盖 LICENSE 列明的 NexusRAG 原创路径。联系邮箱 `commercial-license@nexusrag.io` 为占位，发布前须替换。

### 反思与沉淀

- 双重许可须在 README 首屏与 LICENSE 开篇同时声明，避免用户误以为全库 Apache-2.0 可任意商用。
- GitHub Description / Topics 与 README 品牌一致，便于检索。
