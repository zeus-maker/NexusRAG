## 核心技术概念速查

| 概念 | 含义 | 对应文档 |
|------|------|----------|
| RAG 3.0 | 分类器路由+多通道异构检索+持久化知识编译+混合融合 | 技术架构§1 |
| 四分类器 | 查询复杂度/文档类型/用户意图/安全分级 | 后端逻辑§2.1, 技术架构§3 |
| 五大流水线 | 向量/PageIndex/GraphRAG/Wiki/工具调用 | 后端逻辑§2.2, 技术架构§4 |
| RRF融合 | 多通道检索结果的倒数排名融合 | 后端逻辑§2.3, 技术架构§5 |
| Chunk-Level ACL | 文档块级访问控制 | 后端逻辑§2.4, 数据库§3.1 |
| LLM Wiki | 知识编译持久化（三层：Raw→Entity→Synthesis） | 后端逻辑§2.2.4, 技术架构§4.4 |
| PageIndex | 无向量推理式检索（目录树搜索） | 后端逻辑§2.2.2, 技术架构§4.2 |
| Faithfulness | 忠实度评测指标（≥0.9目标） | 测试用例§7, PRD§5 |
