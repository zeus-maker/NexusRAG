# RAG 3.0 企业级知识库系统 - 前端原型

这是基于详细的RAG 3.0前端设计文档（v1.6）构建的完整交互式Web原型，展示了现代企业级知识库系统的所有核心功能。

## 🎯 项目概述

本项目实现了文档中定义的**RAG 3.0知识库系统**的前端架构，包含：

### 核心模块

1. **知识库管理** (§3 & §10)
   - 知识库列表与创建
   - 文档上传与管理
   - 文件解析预览
   - 分块预览与调整
   - 索引状态监控
   - 检索测试工具
   - 权限管理

2. **智能对话** (§4)
   - 多轮对话界面
   - 消息流式输出
   - 引用溯源
   - 查询链路Trace
   - Chat设置侧栏
   - 答案反馈系统

3. **搜索应用** (§10.6)
   - 搜索应用列表
   - 多渠道搜索结果
   - 相关性排序
   - 高级检索语法

4. **Agent & Pipeline** (§10.7)
   - Agent列表管理
   - 画布编辑器
   - Pipeline执行结果

5. **评测中心** (§5 & §11.5)
   - 关键指标仪表板
   - 评测任务管理
   - 数据集管理
   - 成本中心
   - 满意度分析

6. **系统管理** (§6 & §11)
   - 用户与权限管理
   - 安全与合规
   - 分类器路由配置
   - 融合策略配置
   - GraphRAG/Wiki/PageIndex Hub

## 🏗️ 架构特点

### 双层架构

```
┌─ RAGFlow 兼容层 ─────────┐
│ • 知识库管理（配置/解析）│
│ • Chat & Search          │
│ • Agent Pipeline         │
│ • 用户设置与Admin        │
└──────────────────────────┘

┌─ RAG 3.0 增强层 ─────────┐
│ • Wiki Hub（LLM编译）     │
│ • PageIndex Hub（树索引）  │
│ • GraphRAG Hub（图谱）    │
│ • 四分类器路由            │
│ • 融合与精排策略          │
│ • 安全合规中心            │
└──────────────────────────┘
```

### 导航结构

- **顶栏**：全局搜索、通知、用户菜单、主题切换
- **侧栏**：7大导航菜单 + 可折叠
- **知识库详情**：11项左侧子导航 + 3个Hub (Wiki/PageIndex/GraphRAG)
- **状态栏**：连接状态、环境、版本信息

## 🚀 快速开始

### 环境要求

- Node.js 18+
- npm 或 yarn

### 安装依赖

```bash
npm install
```

### 开发服务器

```bash
npm run dev
```

访问 `http://localhost:5173` 查看实时演示

### 构建生产版本

```bash
npm run build
```

生成的文件在 `dist/` 目录中

## 📦 技术栈

- **React 18.3** - UI框架
- **TypeScript 5.5** - 类型安全
- **Tailwind CSS 3.4** - 样式框架
- **Lucide React** - 图标库
- **Vite 5.4** - 构建工具

